# Word Forge Auth Service

A production-ready Node.js API setup using internal feature-based modular architecture.

## Tech Stack
- Node.js & Express
- TypeScript
- MongoDB with Mongoose
- Zod (Validation)
- AWS SDK v3 & Multer (Image Upload)

## Getting Started

1. Set up your `.env` file based on `.env.example`
2. Run `npm install`
3. Start the dev server: `npm run dev`

## Scripts
- `npm run dev`: Starts the TypeScript server via `ts-node-dev`
- `npm run build`: Compiles TypeScript to JavaScript
- `npm start`: Runs the compiled JS from `dist/`
